How it goes

Three moves. Write, build, check.

  1. Write the words

    Say what the page is for and what it should say. A plain file is fine.

  2. Build the draft

    One command turns the words into a site, and the offline draft costs nothing.

  3. Check the result

    The checker reads every page and fails the job on the first problem. Nothing goes live with a failure on it.

The rules it runs on

Six rules. They hold unless Keith changes them.

Nothing invented

the builder only uses words it was given. A missing fact stays missing.

Hidden first

pages stay out of search results until a person signs off on the words.

Local photos only

a photo must sit in the project folder. Web addresses for photos are dropped.

Keys stay out

the engine reads key names from the environment. The values never touch the disk.

Every run counted

each attempt lands in a ledger with its token count, pass or fail.

Plain Python

version 3.11 or newer, standard library only, nothing to install.

The check gate

The checker reads every page before anything moves. Words against copy, links, photos, and the small print: title, description, noindex. One failure stops the job. Zero is the only passing score.

Seven seats, no publish

One site moves through seven seats in order: architect, content, frontend, graphics, visual critic, SEO, deployer. Each seat does its own job. The last seat writes a ticket. Going live is a person typing a command, and only Keith types that one.

Two clicks to install

Questions

Does the offline draft really cost nothing?
Yes. No model runs. The words are sorted into sections by fixed rules, and the page is assembled from code. The ledger records the run at zero tokens.
What does the AI pass cost?
One planning call, with one retry if the answer comes back broken. On the free tier the cost is zero dollars. The ledger writes down the exact count either way.
Can the AI make things up?
No. It works only from the words in your files. It can reorder and shorten, but it cannot add facts, prices, or names.
How do I change one thing?
Edit the site.json file and rebuild from it with build --from. The rebuild costs nothing. Small fixes beat full rebuilds.
How does a site go live?
A person runs the bind command for the site and the mold. There is no publish button. A mold that is already live somewhere else is refused.
What do I need on my machine?
Python 3.11 or newer. That is all. The offline path needs no keys and no accounts.
