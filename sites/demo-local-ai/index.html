Commands

  1. Build

    - forge init PROJECT: scaffold a project with brief.md and a copy folder. - forge build PROJECT --offline: zero-token build mapped from your copy. - forge build PROJECT: AI build on the free chain, with offline fallback. - forge build --from SITE/site.json: rebuild after hand edits, zero tokens.

  2. Iterate

    - forge refine SITE "instruction": patch one section, small token cost. - forge refine SITE "light theme" --offline: theme flips cost nothing.

  3. Gate and preview

    - forge check SITE: fleet-aligned checks (no_sample, links, noindex, meta). - forge serve SITE: preview on localhost before anything goes anywhere.

House rules the engine enforces

  1. No invented content

    The AI prompt is hard-restricted to your source copy, Values are never written to disk by the engine.

  2. Noindex by default

    Pass --indexable only after a gate is signed.

  3. No hotlinking

    External stock-photo URLs are dropped at ingest.

  4. Secrets by env var name only

    GEMINI_API_KEY, OPENROUTER_API_KEY, OPENWORK_API_KEY.

Questions about the engine

Does the offline build really cost zero tokens?
Yes. The offline planner maps your copy files into sections with deterministic rules, and the renderer assembles the HTML from code. No model is called.
What does an AI build cost?
One planning call, plus at most one repair retry if the reply is not valid JSON. On the Gemini free tier the estimated cost is zero dollars; the ledger in report.json records the exact token counts.
Can the AI invent content?
No. The planning prompt restricts the model to facts and wording present in your source copy. It may reorganize and tighten, but it may not invent facts, prices, names or claims.
How do I change something without tokens?
Edit sites/NAME/site.json by hand and rebuild with forge build --from. The renderer is deterministic, so the rebuild is free.
How does this fit the fleet checks?
The built-in forge check mirrors the fleet content markers, the hotlink blocklist and the noindex rail, so a site that passes forge check is aligned with website_checker content rules before any deploy conversation starts.

About SpiderCaster

SpiderCaster is a copy-driven static website engine. The structure, layout, styling and assembly are deterministic code, so the bulk of every build costs zero tokens. AI is optional and rides the free chain: the Gemini free tier first, then OpenRouter free models, then OpenWork inference. Paid models join only when explicitly allowed.

The engine follows the WebDev package rails: it never invents facts, prices or claims; output stays noindex until approved; secrets are read from environment variable names only; and every run writes a token ledger so the cost is auditable.

Why it is cheap- Deterministic assembly: layout, CSS, icons and pages are code, not tokens. - Offline mode: a full draft with zero tokens, mapped straight from your copy. - One-call AI builds: a single compact planning call produces the whole site - Refine instead of rebuild: edits touch one section, so a revision costs a few hundred tokens instead of a full build. - Hand edits are first-class: edit site.json directly and rebuild for free.
