# How Wix Harmony and Shopify equip a builder

Read 2026-10-01 from public help and developer docs. A procedure is paraphrased next to its URL. If the opened page does not say the step, this file says **not public**. No themes were downloaded.

`library/research/HOW_PRO_BUILDERS.md` already records first input, starter copy, section shape, review, images, and the publish click for Wix Harmony and for Shopify Magic. This file does not repeat that. It records the tools on the work surface, the bounded skills those tools expose, and the environment they run in.

## Wix Harmony — tools

The editor is a canvas plus panels. Released January 2026. Resizing the browser resizes the canvas. https://support.wix.com/en/article/wix-harmony-editor-a-guided-tour

**Action bar.** Select a menu, section, or element. The bar changes. A text element gets font, size, alignment, and formatting. A header gets background and scroll effect. https://support.wix.com/en/article/wix-harmony-editor-a-guided-tour

**Top bar.** Wix logo opens quick site actions: preview, publish, site history, media manager, marketing tools, dashboard, plan, help. **Site Overview** holds domain, favicon, name, and description. **Brand** holds palette, text styles, and button, line, and box themes. **My Business** lists actions for installed apps. The page name opens **Site pages**. **Fit** zooms. **Preview** and **Publish** sit at the top right. https://support.wix.com/en/article/wix-harmony-editor-a-guided-tour

**Add Elements.** **+ Add**, then **Elements**. Find by search, **Upload Media**, or a category icon and a tab. Click or drag onto the page. Rows opened on that table: Text (branded titles, paragraphs, running text, collapsible text), Image, Button, Graphics. Further rows are on the same page and are not copied here. https://support.wix.com/en/article/wix-harmony-editor-adding-elements

**Layers.** Bottom left, **Layers**. Drag a layer up or down. An element stays in its section; moving it to another section is a canvas drag or cut and paste, not a Layers drag. Double-click to rename. The name is editor-only. **More Actions**: cut, copy, paste, duplicate, delete, pin to screen (elements only), arrange (forward, backward, front, back). Header or footer: **Hide header** / **Hide footer**, per page; **Show** brings it back. Mobile icon, then Layers, then **Hide**: gone on mobile, still on desktop. **Hidden from mobile** plus **Show on mobile** reverses that. DOM order optimization is on by default; **More Actions** then **Optimize DOM order** turns it off for one section. The panel has a search box. Section count limit: the FAQ says you can add as many as you need. https://support.wix.com/en/article/wix-harmony-editor-working-with-the-layers-panel

**Right-click.** Cut, copy, paste, duplicate, delete, **Pin to screen**, **Pin settings** (horizontal and vertical distance from the screen edges). Several elements: hold Shift and click. https://support.wix.com/en/article/wix-harmony-editor-using-the-right-click-menu

**Shortcuts** (Windows; Mac uses Cmd for Ctrl and Option for Alt). Save Ctrl+S. Preview Ctrl+P. Desktop/mobile Ctrl+J. Undo Ctrl+Z. Redo Ctrl+Y. Zoom Ctrl+− / Ctrl++. 100% Ctrl+0. Fit Shift+1. Aria chat Ctrl+/. Right-click menu Ctrl+Alt+C. Action-bar panel Space. Shortcut list Ctrl+Alt+K. Add panel Ctrl+Alt+A. Media Manager Ctrl+Alt+M. Close panel Esc. Help Shift+/. Pages Ctrl+Alt+P. Blank page Alt+Shift+P. Blank section Alt+Shift+S. Text: Ctrl+B, Ctrl+I, Ctrl+U, Ctrl+A. Element: Ctrl+X, Ctrl+C, Ctrl+V, Ctrl+D, Delete. Stack order Ctrl+↓ / Ctrl+↑. https://support.wix.com/en/article/wix-%ED%95%98%EB%AA%A8%EB%8B%88-%EC%97%90%EB%94%94%ED%84%B0-%ED%82%A4%EB%B3%B4%EB%93%9C-%EB%8B%A8%EC%B6%95%ED%82%A4

**Brand panel.** **Brand** at the top. Set colors, text, and element styles once; pages follow. You can still restyle one element. Branded pieces stay in Add Elements. Kit: hover the kit, **Change Kit**, pick, leave the tab. While that tab is open, **Current kit** reverts. Colors: Harmony generates a palette of base colors (with shades) and accents. **Colors**, then **Change palette**, or unlock shades and **Apply**. Text: **Text**, then a font set (one heading font, one paragraph font) or **Change All** for headings or paragraphs, or one style (Heading 1, Paragraph 2) for font, size, color, formatting, line spacing. Buttons, boxes, and lines have their own **Change Set** or per-item controls. A brand change applies to matching elements already on the site, including after publish. High-contrast OS themes can hide Brand controls; the page says turn those off, refresh, edit, then turn them back on. The site's saved brand does not change while the OS filter is on. https://support.wix.com/en/article/wix-harmony-editor-setting-up-your-brand

**Site Overview.** Live or not, and the address, at the top. **Connect Domain**. **Add Favicon** uploads the browser-tab icon. Hover a field and **Edit** for name, business type, and description. The page says more specific info makes AI suggestions more relevant. **Edit Brand** jumps to the Brand panel. **Go to SEO Tasks** opens the SEO task list. https://support.wix.com/en/article/wix-harmony-editor-working-with-the-site-overview-panel

**AI Element Generator.** **+ Add**, **Generate with AI**, describe, **Generate Element**. Or hover a suggestion and **Edit prompt** or **Generate**. Review, type more instructions, **Save** into that site's **AI Elements** library (per site, not per account). Reuse: **+ Add**, **AI Generated**, drag. Later: **Edit With AI**, type, **Update Changes**. Action-bar design controls depend on how the element was generated; some changes exist only in that chat. https://support.wix.com/en/article/wix-harmony-editor-generating-an-element-with-ai

**Autosave and preview.** Hover the **Autosave** icon for the last save time. Ctrl+S also saves. **Preview** (top right), then desktop or mobile. Drag the preview slider for other widths. The FAQ on that article: saving stays in the editor for you and your team; publishing is what visitors get. https://support.wix.com/en/article/wix-harmony-editor-previewing-and-publishing-your-site

**Help.** Bottom-left Help icon: tips for the current spot in the editor. https://support.wix.com/en/article/wix-harmony-editor-a-guided-tour

Open: Shopify admin, **Online Store**, **Edit theme** on the theme you want. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview

Three regions. Menu bar: left switches sidebar among sections, theme settings, and app embeds; center is theme name, market, and template; right is the session controls. Sidebar: tree of the current template, collapsible. Preview: updates as you edit; mobile preview and the preview inspector sit here. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview

Theme-name menu: **Edit code**, **Edit default theme content**, open a preview, **View documentation**, keyboard-shortcut list, **Get support**. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview

Session controls: Sidekick on or off, preview inspector on or off, mobile preview, undo, redo, **Save**. Undo and redo apply only to unsaved work. After **Save**, they go inactive. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview

Sidebar width: at least 1600px, two panels (structure left, settings right). Narrower: settings slide up from the bottom and the divider can be dragged. Click the active sidebar button again to collapse to a full-width preview. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview

Status on the theme name: published theme says **Live**. Unpublished says **Draft**. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview

**Theme settings** (sidebar icon) apply to the whole store: typography, colors, social links, cart, and others the theme exposes. Section and block settings do not. Logo: **Theme settings**, **Logo**, optional alt text, **Save**. Favicon: **Theme settings**, then **Logo** or **Favicon** depending on the theme version, then **Save**. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/theme-settings

Colors, two systems on that page. **Color palettes**: Horizon 4.0.0 and later. Named brand colors for the whole theme. A section or block color field can override one use or point at another palette color. Changing a palette color updates every setting that uses it. **Color schemes**: most themes, including free Shopify themes from before Horizon 4.0.0. A scheme is a set (background, text, button) applied per section. You can keep more than one scheme. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/theme-settings

**Preview inspector.** On by default for every free theme from Shopify. Click an outlined element to open its setting. From the preview you can reorder, hide, or duplicate sections and blocks. The same page's tool section also lists move, hide, duplicate, and delete. On a phone, one tap selects; a second tap browses as a customer. Long-press a section in the Shopify app to manage it. **Keyboard** (theme editor). Undo Ctrl+Z / ⌘Z. Redo Ctrl+Y / ⌘Y. Save Ctrl+S / ⌘⇧S. Shortcut list Ctrl+/ / ⌘/. Preview inspector Ctrl+Shift+| / ⌘⇧|. Sidekick Ctrl+. / ⌘.. Hide and show Ctrl+Shift+H / ⌘⇧H. The page also lists preview mode, sections, theme settings, app embeds, remove, select previous/next, open selected, expand all, and collapse all. Some Windows chords in the fetched table repeat the same modifier string; where a cell is ambiguous, the exact chord is **not public** beyond that table. https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview

**Edit code** is a separate directory of Liquid, HTML, CSS, JSON, and JavaScript. Open from the theme-name menu, or from Online Store, the theme menu, **Edit code**. Several files can be open. ## Horizon and the theme-file environment

Architecture, three kinds. Vintage. Online Store 2.0 (sections on pages, dynamic sources, JSON templates). Theme blocks, latest, and the Horizon family is in that kind. Theme-block themes also keep the OS 2.0 features. A draft slot can hold a different architecture than the live theme. Version number (the theme-store update) is not the same thing as architecture. https://help.shopify.com/en/manual/online-store/themes/managing-themes/versions

Check for theme blocks without trusting the marketing name: **Edit code**, sidebar, a **blocks** directory. https://help.shopify.com/en/manual/online-store/themes/theme-structure/sections-and-blocks

Block sources. App blocks, section blocks (defined inside one section), theme blocks (files in `/blocks`, can nest). One section accepts theme blocks or section blocks, not both. Nesting stops at eight levels. A required block can be customized or hidden, not reordered or deleted. A restricted block appears only in the sections that list it. An incompatible drag returns to the old position. Limits: 25 sections per template, 1250 blocks across that template. Per-type caps are set by the theme. https://help.shopify.com/en/manual/online-store/themes/theme-structure/sections-and-blocks and https://help.shopify.com/en/manual/online-store/themes/theme-structure

Add path: **Edit theme**, template drop-down (home is the default), **Add section**, pick or search, then edit the section or **Add block**, drag to reorder, **Save**. https://help.shopify.com/en/manual/online-store/themes/theme-structure/sections-and-blocks

Developer file rules. Theme blocks are Liquid files in `/blocks`. Schema can set `name`, `settings`, `presets`, and child `blocks`. `"@theme"` means other theme blocks. `"@app"` means app blocks. A named type such as `"slide"` restricts the child. Theme blocks cannot define local blocks in that schema; sections can. https://shopify.dev/docs/storefronts/themes/architecture/blocks/theme-blocks/schema

Magic-generated blocks are theme blocks in `/blocks`. A section accepts them only if its schema includes `@theme`. A generated block is not a section. Sidekick generation into a new section is wrapped in `_blocks.liquid`. That wrapper is not a normal section: it cannot be rendered with `{% section '_blocks' %}` and it is not in the merchant **Add section** list. A theme may ship its own `_blocks.liquid`. The documented requirements: accept `@theme` and `@app`, define presets, emit `{% content_for 'blocks' %}`, and do not set `templates` (including inside `disabled_on` / `enabled_on`). https://shopify.dev/docs/storefronts/themes/architecture/blocks/ai-generated-theme-blocks

Directory the CLI will treat as a theme:

```
assets  blocks  config  layout  locales  sections  snippets  templates/customers
```

Subdirectories other than the documented ones are not supported. Only `layout/theme.liquid` is required to upload. `shopify theme dev` runs only in a directory that matches this shape (or an already-built output directory). Extra files stay out via `.shopifyignore` or `--ignore`. https://shopify.dev/docs/storefronts/themes/tools/cli and https://shopify.dev/docs/storefronts/themes/architecture

`shopify theme dev` makes a development theme: hidden, not counted toward the theme limit, deleted after seven days without use, and deleted on `shopify auth logout`. It is for live preview, the admin theme editor, and a password-protected share. It is not the published theme. A preview that survives logout is `shopify theme push` onto an unpublished theme. `shopify theme info` prints the store. `shopify theme check` is the Liquid and JSON linter (syntax, missing templates, unused snippets, unknown tags, performance). The CLI can also `theme publish`; that command is a store publish and is out of scope for SpiderCaster. https://shopify.dev/docs/storefronts/themes/tools/cli and https://shopify.dev/docs/storefronts/themes/tools/theme-check

Who may use the CLI against a store: a collaborator with **Manage themes**, a staff account with **Themes**, or the store owner. A dev store also requires owner or staff. Theme Access passwords and custom-app tokens are alternate auth. Those are credentials. This file does not record any. https://shopify.dev/docs/storefronts/themes/tools/cli

Horizon 4.0.0 color palettes are under Theme settings, above. Whether every Horizon theme uses palettes rather than schemes is stated as "newer themes such as Horizon 4.0.0 and later," not as a per-file audit. A theme-by-theme palette list is **not public** here because no theme was downloaded.

## Five new tools

Stdlib only (`json`, `pathlib`, `datetime`). Offline. No network. No publish. No stock URL. No new section type. Package molds only. Each one fails closed and writes nothing except `session_mark`, which appends one local line.

### 1. seat_gate

- Caller: any of the seven seats. `caller` must equal `seat`.
- Inputs: `caller` (seat id), `seat` (seat id), `hand` (string).
- Output keys: `seat`, `hand`, `allowed`.
- Fail: unknown seat; `caller` differs from `seat`; `hand` not in that seat's `ROLES` list in `lib/crew.py`. Then `allowed` is false. Does not call the hand. Does not read secrets.
- Target file: `lib/crew.py`.
- Why: Harmony roles (Website Designer, Content Writer) and the theme-editor split (sections, theme settings, app embeds) keep one person off another surface. `crew_roles` and `seat` only print. This one refuses.

### 2. layer_read

- Caller: visual.
- Inputs: `out` (built site directory). Optional `write` must be absent.
- Output keys: `layers` (list of `index`, `id`, `type` from `site.json` section order), `page` (first page slug, or empty).
- Fail: `site.json` missing or not JSON; a section `type` not in `ir.SECTION_TYPES`; `out` escapes the working tree or contains `..`; `write` was passed. Read only. Does not reorder.
- Target file: `lib/hands/__init__.py`.
- Why: Harmony Layers and the Shopify sidebar are a tree of what is already on the page. `pagemodel_read` returns the whole IR. This returns the tree and stops.

### 3. code_refuse

- Caller: frontend.
- Inputs: `kind` (string).
- Output keys: `kind`, `refused`, `reason`.
- Fail: `kind` empty; `kind` is `liquid`, `velo`, `javascript`, `css`, or `custom_element`; `kind` contains `http://` or `https://`; `kind` is not one of `ir.SECTION_TYPES`. Writes nothing. If `kind` is an existing section type, status is still a refusal to emit code: `refused` true, `reason` says the type stays in the catalog. That case is the only non-error refusal.
- Target file: `lib/hands/__init__.py`.
- Why: Harmony has no Velo; the element generator is the substitute, and SpiderCaster does not copy it. Magic **Keep** writes a `.liquid` file into `/blocks`. This seat does not.

### 4. mold_panel

- Caller: architect.
- Inputs: `mold_id` (string). If `live` is passed, fail.
- Output keys: `id`, `origin`, `palette`, `type_lead`, `nav`, `template`, `parents`.
- Fail: mold file missing; `origin` not `scratch`, `mutate`, or `mix`; palette not `#` plus six hex digits; any string value contains `http://` or `https://`; `live` was passed. Reads `library/molds/<id>.json` only. Does not write the mold, the ledger, or the vault. Does not download a parent.
- Target file: `lib/library.py`.
- Why: Harmony Brand and Shopify Theme settings are global tokens, separate from one section. `mold_list` lists. `mold_pick` can create. This only shows the package tokens and rejects a URL.

### 5. session_mark

- Caller: deployer.
- Inputs: `out`, `seat`, `hand`, `status`, `detail`.
- Output keys: `path`, `seq`, `seat`, `hand`, `status`.
- Fail: `seat` not in the seven; `hand` not in that seat's list; `status` not `PASS`, `FAIL`, or `SKIP`; `detail` contains `http://` or `https://`; `out` missing or escapes the working tree; a restore flag was passed. Appends one JSON object as a line to `out/session.jsonl`. Does not rewrite earlier lines. Does not restore. Does not write `crew-ticket.json`. Does not bind live.
- Target file: `lib/hands/__init__.py`.
- Why: Harmony history is an append of saves with who and when. Shopify undo dies at **Save** and is not a second publish. This is the local append. Publish stays the Keith click outside `crew run`.
