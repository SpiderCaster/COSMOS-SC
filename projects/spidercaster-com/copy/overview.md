# SpiderCaster turns words into websites.

You write what the page should say. SpiderCaster builds a self-contained website from your words and hands you the files. There is no database. There is nothing to log into. When the words change, you build again.

- The code is the SpiderCaster / COSMOS-SC repository on GitHub.
- Clone the repository and run one offline command.
- Keep every file. The site is yours.
